## Quick Start

## 快速开始

1. Install dependencies

   安装依赖

```bash
pip install -r requirements.txt
```

2. Configure your API key

   配置 API Key

```bash
cp env.example .env
```

3. Run the examples

   运行示例

```bash
python default_tracing.py
python custom_tracing.py
```
