# 教程 7：会话

This chapter shows how to keep conversation history and multi-session state in a Streamlit app.

本章演示如何在 Streamlit 应用中保存对话历史和多会话状态。

## 你将学到什么

  Streamlit 状态处理

## Quick Start

## 快速开始

1. Install dependencies

   安装依赖

```bash
pip install -r requirements.txt
```

2. Configure your API key

   配置 API Key

```bash
cp env.example .env
```

3. Run the app

   运行应用

```bash
streamlit run streamlit_sessions_app.py
```
