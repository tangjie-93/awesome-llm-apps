# Tutorial 9: Multi-Agent Orchestration

# 教程 9：多 Agent 编排

This chapter shows how to coordinate several agents in parallel or by exposing agents as tools.

本章演示如何并行协调多个 Agent，或者把 Agent 当作工具来编排。

## What You'll Learn

## 你将学到什么

- Parallel execution

  并行执行

- Agents as tools

  Agent 作为工具

- Result aggregation

  结果汇总

## Quick Start

## 快速开始

1. Install dependencies

   安装依赖

```bash
pip install -r requirements.txt
```

2. Configure your API key

   配置 API Key

```bash
cp env.example .env
```

3. Run the examples

   运行示例

```bash
python parallel_execution.py
python agents_as_tools.py
```
