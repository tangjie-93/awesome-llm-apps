# Tutorial 3: Tool Using Agent

# 教程 3：工具调用 Agent

This chapter shows how an agent can call functions, built-in tools, and even other agents as tools.

本章演示如何让 Agent 调用函数、内置工具，甚至把其他 Agent 作为工具来使用。

## What You'll Learn

## 你将学到什么

- Function tools

  函数工具

- Built-in tools

  内置工具

- Calculator-style tool use

  类计算器工具调用

- Agents as tools

  将 Agent 当作工具

## Quick Start

## 快速开始

1. Install dependencies

   安装依赖

```bash
pip install -r requirements.txt
```

2. Configure your API key

   配置 API Key

```bash
cp env.example .env
```

3. Run the demos

   运行示例

```bash
python calculator_agent.py
python 3_1_function_tools/agent.py
python 3_2_builtin_tools/agent.py
python 3_3_agents_as_tools/agent.py
```
