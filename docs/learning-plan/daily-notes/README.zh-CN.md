# 每日学习笔记

这里保留统一、可复制的每日笔记模板；按周学习任务仍以各 `week-xx-*` 目录中的 `README.zh-CN.md` 为准。每天完成学习后，在本目录创建一篇笔记，文件名使用 `Wxx-Dxx.md`，例如 `W03-D02.md`。

## 使用方式

1. 打开对应周目录，确定当天的学习任务、必须理解的内容和预期输出。
2. 复制下方模板，创建当天的 `Wxx-Dxx.md` 文件。
3. 当天记录真实输入、输出、失败与改动依据；不得记录 API Key、访问令牌或个人敏感数据。
4. 周末回到对应周文档，完成周末复盘。

## 每日完成标准

一篇笔记必须同时包含：当天学习内容、至少一个待解问题、一次真实运行记录、一个可访问的输出位置、失败或局限，以及明天的单一验证目标。缺少其中任一项，当天任务视为未完成。
