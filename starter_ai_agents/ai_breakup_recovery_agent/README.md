# Breakup Recovery Agent Team
# 分手恢复代理团队

This app helps users process breakup-related emotions with a multi-agent workflow.

这个应用通过多智能体工作流帮助用户处理分手后的情绪。

It is built with Streamlit, Agno, and Gemini 2.0 Flash.

它基于 Streamlit、Agno 和 Gemini 2.0 Flash 构建。

## Features
## 功能特性

- Therapist, closure, routine planner, and brutal honesty agents.
- 心理疏导、情感告别、日常计划和直接反馈四个 Agent。
- Chat screenshot analysis.
- 聊天截图分析。
- Parallel agent execution for richer results.
- 并行执行多个 Agent，得到更完整的结果。
- Streamlit sidebar API key management.
- 在 Streamlit 侧边栏中管理 API Key。

## Setup
## 安装

1. Clone the repository.
1. 克隆仓库。
   ```bash
   git clone https://github.com/Shubhamsaboo/awesome-llm-apps
   cd starter_ai_agents/ai_breakup_recovery_agent
   ```
2. Install dependencies.
2. 安装依赖。
   ```bash
   pip install -r requirements.txt
   ```
3. Run the app.
3. 运行应用。
   ```bash
   streamlit run ai_breakup_recovery_agent.py
   ```

## Usage
## 使用方式

1. Enter how you feel.
1. 输入你的感受。
2. Upload an optional chat screenshot.
2. 可选上传聊天截图。
3. Click Get Recovery Support.
3. 点击获取恢复支持。
4. Review the agent responses and final summary.
4. 查看各个 Agent 的回复和最终总结。
