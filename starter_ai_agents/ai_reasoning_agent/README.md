## AI Reasoning Agent
## AI 推理代理

The AI Reasoning Agent leverages advanced AI models to provide insightful reasoning and decision-making capabilities.

AI Reasoning Agent 使用先进的 AI 模型，提供有洞察力的推理和决策能力。

This agent is designed to assist users in various analytical tasks by processing information and generating structured outputs.

这个代理通过处理信息并生成结构化输出，帮助用户完成各种分析任务。

### Features
### 功能特性

- **Advanced Reasoning**: Utilizes the Ollama model to perform complex reasoning tasks
- **高级推理**：使用 Ollama 模型执行复杂推理任务

- **Interactive Playground**: Provides a user-friendly interface for interacting with the reasoning agent
- **交互式 Playground**：提供友好的界面与推理代理交互

- **Markdown Support**: Outputs results in markdown format for easy readability and sharing
- **Markdown 支持**：以 Markdown 格式输出结果，便于阅读和分享

- **Customizable Agent**: Easily configurable to suit different reasoning scenarios
- **可配置代理**：可轻松配置，以适配不同的推理场景

### How to Get Started
### 快速开始

1. **Clone the repository**:
1. **克隆仓库**：
    ```bash
    git clone https://github.com/Shubhamsaboo/awesome-llm-apps.git
    cd starter_ai_agents/ai_reasoning_agent
    ```

2. **Install the required packages**:
2. **安装所需依赖**：
    #### For Local AI Reasoning Agent
    #### 本地 AI 推理代理
    ```bash
    pip install -r requirements.txt
    ```

3. **Run the application**:
3. **运行应用**：
    ```bash
    python local_ai_reasoning_agent.py
    ```

### Using the Agent
### 使用代理

1. **Access the Playground**:
1. **访问 Playground**：
    - Open the provided URL to access the interactive playground
    - 打开提供的 URL 进入交互式 Playground
    - The playground allows you to input queries and receive structured reasoning outputs
    - Playground 支持输入问题并接收结构化推理结果

2. **Input Queries**:
2. **输入问题**：
    - Enter your queries in the provided input field
    - 在输入框中输入你的问题
    - The agent processes the input and provides detailed reasoning and analysis
    - 代理会处理输入，并给出详细的推理和分析

3. **View Results**:
3. **查看结果**：
    - Results are displayed in markdown format
    - 结果会以 Markdown 格式展示
    - Easily copy and share the outputs for further use
    - 你可以轻松复制并分享输出内容，便于后续使用
