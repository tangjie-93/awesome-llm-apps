# Starter AI Agents
# Starter AI Agents

This directory collects starter AI agent demos.

这个目录收集了一组入门级 AI Agent 示例。

Each subfolder is an independent project with its own entry script and dependencies.

每个子文件夹都是一个独立项目，通常有自己的入口脚本和依赖。

## Quick Start
## 快速开始

1. `cd starter_ai_agents/<project>`
1. `cd starter_ai_agents/<项目文件夹>`
2. `pip install -r requirements.txt`
2. `pip install -r requirements.txt`
3. `streamlit run <entry>.py`
3. `streamlit run <入口脚本>.py`

- `ai_life_insurance_advisor_agent`：估算定期寿险保额并给出产品建议。

- `ai_meme_generator_agent_browseruse`：自动化梗图相关的浏览器流程。

- `ai_music_generator_agent`：根据文本提示生成音乐。

- `ai_reasoning_agent`：对比云端与本地模型的推理流程。

## Notes
## 注意事项

- These demos are for learning and prototyping.
- 这些示例主要用于学习和原型验证。
- Medical, insurance, finance, and emotional support outputs should not be treated as professional advice.
- 医疗、保险、金融和情绪支持类输出不能当作专业建议。
- Check each subfolder README for the exact entry script and API keys.
- 具体入口脚本和 API Key 以各子目录 README 为准。
