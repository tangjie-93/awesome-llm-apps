# ModelsLab Music Generator
# ModelsLab 音乐生成器

This Streamlit app generates music from text prompts.<br>
这个 Streamlit 应用可以根据文本提示生成音乐。

It uses ModelsLab for music generation and OpenAI for prompt processing.<br>
它使用 ModelsLab 生成音乐，并使用 OpenAI 处理提示词。

## Features
## 功能特性

- Generate music from a detailed prompt.<br>
  根据详细提示词生成音乐。
- Output MP3 files for listening or download.<br>
  输出 MP3 文件，便于收听或下载。
- Simple Streamlit interface.<br>
  简洁的 Streamlit 界面。
- API keys entered in the sidebar.<br>
  在侧边栏中输入 API Key。

## Setup
## 安装

1. Clone the repository.<br>
   克隆仓库。

   ```bash
   git clone https://github.com/Shubhamsaboo/awesome-llm-apps
   cd starter_ai_agents/ai_music_generator_agent
   ```

2. Install dependencies.<br>
   安装依赖。

   ```bash
   pip install -r requirements.txt
   ```

3. Run the app.<br>
   运行应用。

   ```bash
   streamlit run music_generator_agent.py
   ```

## Usage
## 使用方式

1. Enter your OpenAI and ModelsLab API keys.<br>
   输入 OpenAI 和 ModelsLab 的 API Key。

2. Describe the music you want to generate.<br>
   描述你想生成的音乐风格。

3. Click Generate Music.<br>
   点击生成音乐。

4. Play or download the MP3 result.<br>
   播放或下载生成的 MP3 结果。
