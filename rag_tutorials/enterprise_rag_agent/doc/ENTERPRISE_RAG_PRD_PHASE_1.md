# Enterprise RAG PRD - 阶段 1：最小可用 RAG

> 版本：v0.1
> 日期：2026-08-13

## 目标

跑通稳定的问答链路。

## 范围

- 文档接入
- 文档解析与切块
- 基础检索
- 结果引用
- 简单问答
- 基础日志

## 需求

1. 支持批量导入目录下文档。
2. 支持按结构切块并保存元数据。
3. 支持问题检索和问答返回。
4. 支持回答引用来源片段。
5. 支持基础操作日志。

## 验收

- 任意一批样例文档可以导入。
- 问题可以返回答案和引用。
- 无结果时系统能明确说明证据不足。

## 待确认

- 首批支持的文档格式
- 切块策略是否需要按文档类型分化
- 是否要先支持手工导入还是目录同步
