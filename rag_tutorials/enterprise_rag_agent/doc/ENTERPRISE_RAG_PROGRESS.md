# Enterprise RAG 需求完成进度

> 版本：v0.3
> 最近更新：2026-08-19

## 维护规则

- 每次新增、修改或完成需求后，必须同步更新本文档。
- 阶段状态只使用：`未开始`、`进行中`、`基本完成`、`完成`、`阻塞`。
- 完成度是产品和实现综合判断，不等同于代码行数或接口数量。
- 如果某项能力已有代码但缺少验收、文档或前端入口，只能标记为 `进行中` 或 `基本完成`。

## 总体判断

阶段 0 的需求定义和只读展示已经完成，可以作为后续阶段的输入继续推进。

完成依据：

- 业务范围、权限规则、配置约定、前端只读展示需求和阶段 0 边界清单已单独成文并纳入 PRD 索引。
- 后端已提供 `/api/config` 和 `/api/scope`，统一输出知识库、权限组、风险等级、业务域和排除范围。
- 前端范围页已从后端同步只读范围数据，不再硬编码业务边界。
- 文档和切块已带有 `risk_level`，回答日志会记录高风险内容是否需要人工复核。

## 风险和待确认

- 模型 embedding 依赖 `ENTERPRISE_RAG_EMBEDDING_API_KEY` 或 LLM API key；无 key 的本地测试需显式配置 `ENTERPRISE_RAG_EMBEDDING_PROVIDER=local`。
- 目录同步清理只在目录导入时触发，单文件导入不会清理其他索引；该行为已由后端测试覆盖。
- 同内容跨不同知识库按全局去重处理；如业务需要分知识库保留重复内容，需要重新调整去重范围。
- 当前权限模型已切换为 JWT/OIDC 身份声明来源；本地开发仍可通过 `ENTERPRISE_RAG_AUTH_MODE=off` 保持免登录。
- 租户 ID 默认从 `ENTERPRISE_RAG_JWT_TENANT_CLAIM`（默认 `tenant_id`）读取；免登录开发模式使用 `ENTERPRISE_RAG_DEFAULT_TENANT_ID`。
- 审计删除/清理需要 `ENTERPRISE_RAG_AUDIT_APPROVAL_TOKEN`，否则接口会拒绝破坏性操作。
- 诊断失败导入回放同样要求 `ENTERPRISE_RAG_AUDIT_APPROVAL_TOKEN`，并且只允许处理当前租户的失败 `ingest` 操作。
- 图片检索当前读取 PNG/JPEG 的文件名、尺寸和可选同名说明文件；没有接入 OCR 或视觉模型，因此不能推断未被人工说明覆盖的图片语义。
- 成本统计为粗粒度事件计数和 token 估算，若要对外出账仍需再接模型单价和更精确 usage。
