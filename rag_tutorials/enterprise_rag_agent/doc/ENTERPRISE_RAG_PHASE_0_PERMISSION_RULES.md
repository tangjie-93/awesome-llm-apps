# Enterprise RAG 权限规则说明

> 版本：v0.1
> 日期：2026-08-13

## 目的

定义阶段 0 的最小可用权限规则，保证检索和回答链路不越权。

## 现有权限组

- `public`
- `security`
- `hr`
- `it`
- `ops`

## 基本规则

1. 文档默认归属 `public`。
2. 敏感文档必须显式指定权限组。
3. 检索结果必须先过滤权限，再进入最终回答。
4. `public` 对所有用户可见。
5. 其他组仅允许同组用户访问。

## 风险内容规则

- `low`：可直接回答。
- `medium`：可直接回答，但保留引用。
- `high`：允许模型生成答案候选，但必须人工复核和审批后才可对外使用。

## 组映射建议

- `security`：安全制度、访问控制、事件响应
- `hr`：入职、培训、员工手册
- `it`：备份、运维、基础 IT 规范
- `ops`：运维相关的补充操作组

## 数据流要求

1. 导入时写入 `allowed_groups`。
2. 查询时传入 `user_groups`。
3. 检索层做一次过滤。
4. 回答层再做一次确认。
5. 高风险内容进入回答前必须留审计信息。

## 前端要求

- 文档详情页应展示权限组。
- 高风险内容应显式标记。
- 若无权限，应展示拒绝访问或无结果说明。
