# Enterprise RAG PRD - 阶段 0：需求和边界

> 版本：v0.1
> 日期：2026-08-13

## 目标

把项目边界说清楚，避免后续实现偏题。

## 范围

- 服务部门和业务域
- 数据源类型和接入方式
- 敏感数据范围
- 权限模型
- 错误答案的业务风险
- 本期做什么、不做什么

## 需求

1. 明确首批服务对象。
2. 明确首批文档类型。
3. 明确权限粒度。
4. 明确风险分级。
5. 明确阶段划分和交付边界。

## 验收

- 有统一的业务范围说明。
- 有明确的风险边界和权限边界。
- 有可执行的迭代路线。

## 待确认

- 首批业务部门
- 首批知识库范围
- 敏感数据范围
- 文档权限最小粒度
