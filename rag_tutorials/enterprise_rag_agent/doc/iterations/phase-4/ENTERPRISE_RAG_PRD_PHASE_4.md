# Enterprise RAG PRD - 阶段 4：高级能力

> 版本：v0.1
> 日期：2026-08-13

## 目标

按业务需要引入更高阶能力。

## 范围

- 多知识库路由
- Agentic RAG
- Web fallback
- 知识图谱
- 多模态检索
- 自动诊断
- 人工反馈闭环

## 需求

1. 支持复杂路由和工具调用。
2. 支持外部信息补充。
3. 支持知识图谱或多跳推理。
4. 支持图片等多模态检索。
5. 支持自动诊断与反馈闭环。

## 验收

- 高级能力可独立开关。
- 不影响基础问答链路稳定性。

## 待确认

- 哪些高级能力有明确业务价值
- 哪些能力只做预留不做首发
- 是否需要单独的诊断页面
