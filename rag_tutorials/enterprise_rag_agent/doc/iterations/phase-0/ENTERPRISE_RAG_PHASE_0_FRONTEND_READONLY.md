# Enterprise RAG 阶段 0 前端只读展示需求

> 版本：v0.1
> 日期：2026-08-13

## 目的

让前端在阶段 0 先具备“可见、可查、可解释”的只读信息展示，不把业务边界藏在后端。

## 需要展示的内容

- 当前公司名
- 默认知识库
- 现有知识库列表
- 现有文档列表
- 文档权限组
- 风险等级说明
- 阶段 0 边界说明
- 已确认业务范围

## 页面建议

1. `dashboard`：展示知识库、文档、问答日志、评估日志概览。
2. `knowledge-bases`：展示知识库列表和对应说明。
3. `documents`：展示文档标题、路径、版本、权限组。
4. `ask`：保留提问入口，同时展示当前知识库和权限上下文。
5. 新增 `scope` 页面：只读展示阶段 0 边界、业务范围和权限规则。

## 交互要求

- 所有只读信息必须可刷新。
- 无权限结果必须明确提示。
- 高风险内容必须显式标识。
- 文档和知识库列表必须能从后端同步。

## 展示要求

- 只读页面不允许修改配置。
- 不在页面中硬编码业务边界。
- 页面文案要和后端配置保持一致。

## 验收

- 用户可以看到首批业务范围。
- 用户可以看到知识库和权限组。
- 用户可以识别高风险内容。
- 用户可以知道哪些内容当前不做。
