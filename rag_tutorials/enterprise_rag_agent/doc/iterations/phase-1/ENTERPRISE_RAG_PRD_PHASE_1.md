# Enterprise RAG PRD - 阶段 1：最小可用 RAG

> 版本：v0.2
> 日期：2026-08-17

## 目标

跑通稳定的问答链路。

## 范围

- 文档接入
- 文档解析与切块
- 基础检索
- 结果引用
- 简单问答
- 基础日志

## 需求

1. 支持批量导入目录下文档。
2. 支持按结构切块并保存元数据。
3. 支持问题检索和问答返回。
4. 支持回答引用来源片段。
5. 支持基础操作日志。

## 当前完成情况

- 后端已支持目录和单文件导入，并返回新增文档、切块、跳过、清理和重复路径明细。
- 后端已支持 Markdown、纯文本、JSON、CSV 和 PDF 文档解析；阶段 1 样例文档以 Markdown 为主。
- 文档和 chunk 已保存知识库、路径、标题、版本、权限组、风险等级、内容哈希、导入时间和切块元数据。
- 检索和问答接口已返回候选片段、打分、引用、证据片段、置信度和无结果说明。
- 回答日志和评估日志已落库，回答日志包含知识库、用户组和高风险复核要求。
- 前端已提供导入、文档、检索、提问和日志页面。
- 导入页已展示导入、跳过、清理、重复路径和知识库明细。
- 文档页已展示内容哈希、知识库、权限组、风险等级、路径和导入时间。
- 检索和提问页已补齐空问题、无结果和异常提示。

## 验收

- 任意一批样例文档可以导入。
- 问题可以返回答案和引用。
- 无结果时系统能明确说明证据不足。
- 导入结果能看到新增、跳过、清理和重复路径明细。
- 文档列表能看到内容哈希、知识库、权限组、风险等级、路径和导入时间。

## 已确认

- 首批样例文档使用 Markdown；后端同时保留纯文本、JSON、CSV 和 PDF 解析能力。
- 当前阶段采用通用结构切块，不按文档类型进一步分化。
- 当前阶段同时支持手工输入路径导入和目录同步导入；目录导入会清理同目录下已不存在的旧索引。

## 后续不纳入本阶段

- 管理端审批流
- 企业级审计报表
- 多租户隔离
- 自动化召回评估集
